# LeadsLift Skill Packs — Start Here

Free, ready-made skills for small business owners. Each skill is one file. Use it in Claude or in ChatGPT (or Gemini). You need your own AI account. LeadsLift does not supply it.

## What a skill file is

A skill is a set of instructions you give to AI once, so it does a job the same good way every time. You paste your real details (a customer message, a price). The AI gives you a draft. **You read it and send it.** AI never sends anything for you.

## Use in Claude (3 ways, easiest first)

1. **Quick:** open a new chat. Paste the whole skill file. Then paste your task.
2. **Better:** make a Claude **Project**. Add the skill files as project knowledge. Every chat in that project can use them.
3. **Best:** if your Claude plan supports **Skills**, upload the skill file (the part from `---` to the end). Claude loads it by itself when your task matches.

## Use in ChatGPT (3 ways, easiest first)

1. **Quick:** open a new chat. Paste the **"Quick paste version"** at the bottom of the skill file. Then paste your task.
2. **Better:** make a ChatGPT **Project**. Paste the Quick paste versions into the project instructions.
3. **Best:** make a **Custom GPT** for one pack. Paste that pack's Quick paste versions as its instructions.

Menu names in these apps change often. If you cannot find a menu, use the "Quick" way. It always works.

## Safe-use rules (read once)

- Do **not** paste card numbers, passwords, ID numbers, or health details.
- Remove customer names and phone numbers when you can.
- **Read every draft before you send it.** Check prices, dates, and promises. AI can make things up.
- Skills give drafts and guides. They are **not legal, medical, tax, or financial advice.**
